# LUIS ARCADE - 16 functions in one Tiny Tapeout chip

LUIS ARCADE is a Tiny Tapeout design (Wokwi flow, 1x1 tile) made only from **477 logic gates and 17 flip-flops**.
Four modes share one 7-segment display:

| MODE (`ui[7:6]`) | Function |
|---|---|
| `00` Sign | 4 scrolling messages: HOLA LUIS CHIP, TINY TAPEOUT, SUERTE LUIS 2026, FLAPPY LUIS |
| `01` Dice | d6, d8, d4 and a coin (H / t) |
| `10` Counter | hexadecimal, decimal, spinner and double spinner, up or down, 4 speeds |
| `11` Safe | 3-digit combination lock (code 5 - C - 9) |

- Wokwi project (public): <https://wokwi.com/projects/476711427277175809>
- Datasheet: [docs/info.md](docs/info.md)
- Author: Luis Lasso

The design was checked against an independent behavioural model: 126,294 test vectors on the Verilog generated by Wokwi, 0 mismatches.

A previous version of this repository (a small 8-bit code safe) is kept in the branch `respaldo-caja-fuerte`.

## What is Tiny Tapeout?

Tiny Tapeout is an educational project that aims to make it easier and cheaper than ever to get your digital and analog designs manufactured on a real chip.

To learn more and get started, visit https://tinytapeout.com.
